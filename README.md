# FNP Sales Analysis 📊

## 📌 About the Project

This project analyzes **FNP (Ferns N Petals) sales data** to identify sales trends, customer behavior, product performance, and other important business insights.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Dashboard

## 📊 Analysis

The project includes analysis of:

* Sales and revenue
* Orders and products
* Product categories
* Customer locations
* Occasions
* Sales trends
